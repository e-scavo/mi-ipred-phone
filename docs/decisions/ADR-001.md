# ADR-001 — Decisiones iniciales (2026-10-09)
- Gratis para usuario final; preferencia 100% open source en componentes propios y SDK; verificar licencias de dependencias, incluyendo copyleft.
- Go en repositorio `e-scavo/mi-ipred-phone-backend`; Flutter en `e-scavo/mi-ipred-phone`.
- Backend desde cero; referencias de GERYON permitidas, sin acoplar repositorios.
- Asterisk SIP/PJSIP por defecto; IAX2 excluido de MVP.
- Caddy/Let's Encrypt con renovación automática para API HTTPS.
- Android Google Play automatizado (AAB/fastlane/API) y Windows compilable; iOS al final con macOS, TestFlight/App Store.
- La POC debe comprobar Windows además de Android; la elección definitiva de stack SIP queda condicionada a ello.
- E4 incluye push/background: no considerar E3 equivalente a softphone móvil de producción en segundo plano.
