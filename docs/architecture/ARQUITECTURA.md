# Arquitectura
Flutter (Android/Windows/iOS) --HTTPS--> Go API (Caddy TLS ACME) --BD propia--> usuarios/dispositivos/cuentas. Flutter --SIP TLS/WSS + SRTP/DTLS-SRTP según pila--> Asterisk PJSIP. No asumir interoperabilidad SIP/WebRTC hasta POC real. Para llamadas entrantes suspendidas: Asterisk / gateway push / APNs-FCM / app; diseño detallado en E4. Asterisk y API tienen ciclos de vida y credenciales separados. Credenciales de línea entregadas solo a dispositivos autorizados y guardadas con almacenamiento seguro. Preferir infraestructura autogestionada; FCM/APNs son servicios de plataforma inevitables para push móvil. Windows no usa permisos/contactos de Android ni CallKit iOS.
